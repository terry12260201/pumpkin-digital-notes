# 🎃 小南瓜數位筆記

> **一句話：** 你丟一支影片給它，它還你一份「看一頁就懂」的圖文報告，順便幫你收好、貼好標籤，以後找得回來。

這個空間放的就是產出來的成品——一篇篇的圖文報告，加上一個可以搜尋、可以用標籤篩選的首頁。

---

## 🤔 這在解決什麼問題？

看影片有三個很煩的地方：

1. **要花時間。** 一場演講一小時，真正的重點可能只有八分鐘。
2. **看完會忘。** 當下覺得「哇好棒」，兩週後只記得「好像有個很厲害的東西」。
3. **找不回來。** 想引用某句話，只記得「是某個戴眼鏡的人講的」，卻不知道在哪支影片第幾分鐘。

**小南瓜數位筆記就是為這三件事做的：幫你看、幫你寫、幫你收好。**

---

## ⚙️ 它會做什麼？四個動作

| 步驟 | 它做的事 | 你拿到什麼 |
|---|---|---|
| **① 看** | 把影片的畫面一張張抓下來，把講者講的每一句話（連同第幾秒）也抓下來 | — |
| **② 挑** | 從幾百張畫面裡挑出 12～18 張真正有資訊的——換投影片、做示範、講金句的那幾張 | — |
| **③ 寫** | 用**白話**重寫一遍。每張圖旁邊標「這是第幾分幾秒」。難字另外做小辭典 | 一份圖文報告 |
| **④ 收** | 收進書架、貼好標籤、上傳成一個網頁 | 一個網址 |

## 📄 一篇報告長什麼樣？

由上到下：

```
🖼️  封面主視覺        ← 一眼認出是哪一場
📋  基本資料          ← 誰講的、多長、你哪天讀的、原始出處
💬  一句話大綱        ← 沒空看完就看這句
🗂️  目錄              ← 想跳到哪一段自己選
📝  分段詳解          ← 每段配 1~2 張截圖，圖上標時間，點下去跳回影片那一秒
📖  專有名詞小辭典     ← 內文看到 ❓ 就點，跳過來看解釋
🎯  這對我有什麼用     ← 不是摘要，是「所以我該做什麼」
```

**幾個刻意的設計：**

- **每張截圖都是一個重點**，不是插圖。看圖就能抓到大概，想細看再點時間跳回原片。
- **文字寫到國小生也看得懂**。專業內容照講，但用生活比喻（例：Webhook 就是門鈴、AI Agent 就是會幫你跑腿的小幫手）。
- **整份報告只有一個檔案**。圖片是直接寫進檔案裡的，寄給別人不會破圖。
- **手機和電腦都好讀**，交付前一定兩邊都看過。

## 🗂️ 怎麼分類：書架 + 標籤

筆記一多，光靠「一個資料夾」就會找不到東西。所以分成兩層。

### 第一層：書架（一篇只能放一個）

**書架 = 這篇從哪來。** 決定它放在哪一區。

- 一個活動、一場年會 → 開一個書架。書架底下還可以再分場次。
- 零散的 YouTube 影片 → 放「YouTube 精選」。

> 📚 **開新書架的門檻：** 同一位 YouTube 作者要累積**滿 3 篇**才給他專屬書架。
> 不然你會很快得到一排只有一篇的空書架，反而更難找。

### 第二層：標籤（一篇可以掛好幾個）

**標籤 = 這篇在講什麼、能拿來幹嘛。** 用來橫向串連——同一個標籤可能散在好幾個書架裡。

標籤都是「**族／名稱**」的格式，分三族：

| 標籤族 | 意思 | 例子 |
|---|---|---|
| `主題／` | 這篇在講什麼 | `主題／AI代理人`、`主題／VibeCoding`、`主題／團隊導入` |
| `用途／` | 能拿來幹嘛 | `用途／照著做`（有明確步驟可以複製）、`用途／建立觀念`、`用途／案例故事`、`用途／工具評測` |
| `關聯／` | 跟你哪件事有關 | `關聯／某某專案` |

**規則：**
- 一篇 **3～5 個**剛好，超過 6 個等於沒分類。
- 至少要有 **1 個 `主題／` ＋ 1 個 `用途／`**。
- 先用現有的詞，真的沒有才新增。
- 🔤 **標籤不能有空格**——寫 `VibeCoding`，不寫 `Vibe Coding`。

> 💡 **為什麼用「／」？** 筆記軟體（Obsidian）看到斜線會自動把標籤收成一棵**可以折疊的樹**。
> 點開「主題」，底下就列出所有主題標籤，不會跟別的混在一起。

## 🔍 首頁能做什麼

1. **搜尋框** — 打字就即時過濾，標題、講者、重點、標籤全都會搜。
2. **標籤篩選** — 點開「🏷️ 用標籤篩選」，點幾個標籤就過濾幾個條件（**多選 = 要同時符合**）。旁邊的篇數會即時跟著變。
3. **一鍵清除** — 「清除全部條件」回到全部。

例如想找「講 AI 代理人、而且有具體步驟可以照著做」的那幾篇，就點 `AI代理人` ＋ `照著做`，兩下就篩出來。

## 🚀 怎麼開始用

這是一支 **Claude Code 的 skill**（可以想成「幫 AI 助理裝一套專門的工作流程」）。

裝好之後，跟 Claude 說任何一句就會啟動：

- 「幫我把這支影片做成數位筆記」＋ 連結
- 「小南瓜數位筆記，整理這支影片」
- 或直接輸入 `/pumpkin-digital-notes`

它會自己跑完：抽畫面 → 抓逐字稿 → 挑重點 → 寫白話報告 → 決定書架和標籤 → 產出網頁 → 存進筆記庫。

## 📖 專有名詞小辭典

看不懂上面哪個詞，查這裡：

| 詞 | 白話解釋 |
|---|---|
| **skill** | 幫 AI 助理裝的一套「專門工作流程」。裝了之後它就知道這件事該怎麼做、要做到什麼標準 |
| **Claude Code** | 一個可以在電腦上跑、會自己動手做事的 AI 助理 |
| **AI Agent（AI 代理人）** | 會**自己動手做事**的 AI，不是只回答問題。像是會幫你跑腿的小幫手 |
| **逐字稿／字幕檔** | 講者說的話變成文字，而且每一句都標了第幾秒。有它就不用另外做語音辨識，又快又準 |
| **標籤（tag）** | 貼在筆記上的小紙條。一篇可以貼很多張，點一下就找出所有貼同一張的 |
| **書架（shelf）** | 這裡自訂的第一層分類。一篇只能放一個，決定它歸在哪一區 |
| **時間戳（timestamp）** | 「第幾分幾秒」。在報告裡點下去可以直接跳回影片的那一刻 |
| **GitHub Pages** | 一個免費的網頁空間。把網頁檔丟上去就變成一個可以打開的網址 |
| **noindex** | 寫在網頁裡的一句話，告訴 Google「不要收錄我」。所以搜尋不到 |
| **base64 內嵌** | 把圖片變成一長串文字直接寫進網頁檔。好處是**整份報告只有一個檔案**，轉寄不會破圖 |
| **Obsidian** | 一套筆記軟體，檔案是純文字、存在自己電腦裡。這裡的報告會同時存一份進去 |
