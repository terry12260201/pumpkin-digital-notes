🤔 這到底在做什麼？（用生活例子講）

假設你家裡有一個很聰明的小幫手（就是那個 AI Agent），它平常只待在你的電腦裡。你不在電腦前的時候，就沒辦法叫它做事，很可惜。

這支影片就是要把這個小幫手，接到大家每天都在用的 LINE 上面。接好以後，你走到哪裡，只要打開手機的 LINE 打幾個字，它就會在背後幫你做事，再把結果傳回你的 LINE。就像有個小秘書一直跟在你身邊。

🎯 為什麼要這樣做？影片說：「你不可能隨時盯著電腦，但 LINE 是我們每天都在用、幾乎人手一個的東西。如果 AI 能直接在 LINE 裡回你，那就完全不一樣了。」

1️⃣ 第一步：去拿兩把鑰匙（0:53–5:07）

要讓程式跟 LINE 講話，得先去 LINE Developers 這個官方網站報到，最後拿到兩把很重要的鑰匙。過程有點像去辦一張新的 LINE 官方帳號：

① 先建一個 Provider（你的開發者身分），影片取名叫「HermesBot」。
② 在底下再開一條 Messaging API 類型的 專線。
③ 過程中系統會順便幫你開一個 LINE 官方帳號（名字隨便取、種類選「軟體／網路」那類、不用申請認證）。

接著就是拿鑰匙。第一把鑰匙叫 Channel Secret（一串 32 個字的密碼），第二把鑰匙叫 Channel Access Token（一串很長的字），要按一下「Issue（生成）」按鈕才會出現。

🔒 老師特別叮嚀：這兩把鑰匙就等於你的帳號密碼，一定要複製到安全的地方，絕對不要讓它出現在公開的影片或截圖裡。（連老師自己錄影時都把鑰匙打上馬賽克。）

2️⃣ 第二步：幫電腦開一條「外面進得來的路」（5:07–6:40）

這一步的觀念最重要，我用門鈴來比喻。

當有人在 LINE 傳訊息給你，LINE 會想辦法「按你電腦的門鈴」，通知它有新訊息——這個門鈴機制就叫 Webhook。可是問題來了：你的 AI 小幫手住在你家電腦裡，外面的人根本不知道你家在哪、按不到門鈴。

所以要用一個工具 ngrok，幫你家裝一條「臨時的公開門牌（一個 HTTPS 網址）」，這樣 LINE 才找得到你、按得到門鈴。

做法很簡單，打開終端機打一行字：ngrok http 8646（8646 是這個 AI 用的門號）。它會給你一個 https://xxxxx.ngrok-free.app 的網址。最關鍵的小地方：把這個網址貼到 LINE 的時候，結尾一定要加上 /line/webhook。

3️⃣ 第三步：把鑰匙填進 AI 的設定裡（6:40–8:07）

現在回到 AI 小幫手（Hermes）的畫面，把剛剛拿到的東西填進去。它內建就支援 LINE，不用另外裝東西。要填三格：

• 第二把鑰匙（Channel Access Token）
• 第一把鑰匙（Channel Secret）
• 准許名單（Allowed IDs）← 這格最多人忘記！

⚠️ 最容易踩的雷：那個「准許名單」(Allowed IDs) 如果空著不填，就算你把 AI 加成好友，它也不會理你。要把你自己的 LINE User ID（你的 LINE 專屬編號）填進去。填完存檔後，還要下指令把 Hermes 的大門 重開一次，再回 LINE 後台按 Verify（驗證） 就會成功。

4️⃣ 第四步：拿手機來玩玩看（8:07–13:50）

用手機掃 QR Code 或搜尋，把這個官方帳號加成好友，傳一句話試試。如果它沒回，先別緊張——最常見的原因是後台有一個 「Use Webhook（使用門鈴）」的開關忘了打開（它預設是關的）。打開後再傳，它就會乖乖回你了。

還有更好玩的：老師在 AI 裡裝了一個「畫四格漫畫」的 技能。你只要在 LINE 打字說想要什麼（例如「說一個關於職場的笑話」），AI 就會先想好每一格要畫什麼，再用會畫圖的 GPT Image 2 一格一格畫出來，最後拼成一張四格漫畫傳回 LINE 給你。

🖼️ 小提醒：如果你要讓 AI 傳「圖片」回 LINE，還要多填一格叫 LINE Public URL 的欄位，一樣把 ngrok 那個網址填進去（但這次結尾不要加 /line/webhook，只填最前面的部分）。不然圖會傳不出來。

⚠️ 三個最常卡住的地方（照做就不會錯）

容易出錯的地方正確做法（白話）
① 網址結尾那個公開網址的最後面要加 /line/webhook，忘了加就連不上。
② 門鈴開關後台的 「Use Webhook」開關要打開（預設是關的），不開 LINE 不會通知 AI。
③ 准許名單要把你自己的 LINE 編號填進准許名單，不然加了好友它也不理你。
④（有圖片才要）要傳圖回 LINE，記得多填一格 LINE Public URL。

🌟 這個 AI 跟一般聊天 AI（像 ChatGPT）差在哪？影片結尾說：一般聊天 AI 很強，但每次聊天都是從頭開始，不會記得你。這個 Hermes 不一樣的兩點是——① 它能把你教它的做法存成一項技能，下次直接用；② 它會越用越懂你，每次你給的回饋都變成它下次做更好的養分。這才像真正的私人秘書。

專有名詞白話解釋
AI Agent（AI 代理人）一個會幫你做事的 AI 小助手。你交代它一句話，它會自己想辦法、動手完成，不只是回答問題。
Skill（技能）AI 學會的一項本領。學會之後，下次你叫它，它就能直接做，不用重教一次。
LINE DevelopersLINE 官方給工程師用的後台網站。想讓程式跟 LINE 連在一起，就要來這裡申請。
Provider（提供者）你在 LINE 後台的「開發者身分證」。之後做的東西都掛在這個身分底下。
Channel（頻道）一條讓你的程式跟 LINE 對話的專線。這支影片建的是「訊息類」的專線。
Messaging APILINE 提供的一組「傳訊息的管道」。有了它，程式才能自動幫你收發 LINE 訊息。
Channel Secret（頻道密鑰）一組 32 個字的密碼，用來證明「這條專線真的是你的」。要保密。
Channel Access Token（存取金鑰）另一把很長的鑰匙，程式拿它才能用你的名義發 LINE 訊息。跟密碼一樣要藏好。
Webhook（網路門鈴）把它想成門鈴。有人在 LINE 傳訊息，LINE 就會自動「按你電腦的門鈴」，通知它：有新訊息囉！
ngrok（臨時公開地址）幫你家（你的電腦）裝一條「臨時的公開門牌」，外面的人才找得到你家、按得到門鈴。
HTTPS 網址一個「有加密、比較安全」的網站地址，開頭是 https://。
Port（連接埠）電腦上的一個「門號」。不同程式用不同門號，這支影片的 AI 用的是 8646 號門。
Allowed IDs（白名單）一張「准許名單」。只有名單上的人，才能跟你的 AI 用 LINE 聊天。
LINE User ID每個 LINE 使用者的一組專屬編號，像身分證號。把自己的填進白名單，AI 才會回你。
Hermes Gateway（閘道）Hermes 這個 AI 對外的「大門」。改完設定要把大門重開一次，新設定才會生效。
GPT Image 2OpenAI 做的一個「用文字畫圖」的 AI。你打字描述，它就畫出圖片。
Verify（驗證）LINE 後台的一個「測試連線」按鈕。按下去，確認門鈴真的按得到你電腦。
